# Renuka Birthday Book

A single self-contained birthday web page.

Flow: confirmation gate -> a letter -> **View the beauty** (the photo book) -> back from the book, a surprise balloon that pops into a message.

Everything (photos, music) is embedded in `index.html`, so the one file is all you need. Open it, or view it live via GitHub Pages.

`build_book.py` is the pipeline that bakes images into the book.
